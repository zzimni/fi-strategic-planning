# 나라장터 공고 스캐너 스킬

## 개요

나라장터 공고를 자동 수집·필터링·평가하여 핀인사이트가 **자격을 갖추고 강점을 가진 공고**만
추려준다. 핵심 차별점은 **핀인사이트 나라장터 등록업종 5개 기반 자격 필터**다.
공고문에 명시된 면허·자격 제한과 핀인사이트의 등록업종을 매칭하여 입찰 참여 가능성을
사전 판단한다.

**핵심 원칙:**
- 공고 수집은 **조달청 OpenAPI 우선**, 실패 시 **Claude in Chrome 폴백**
- **핀인사이트 등록업종 5개 자격 필터를 1차 통과 기준으로 사용**
- 적합도 평가는 핀인사이트 강점 도메인 기반 (빅데이터/AI/AI·데이터 리터러시 교육)
- 결과는 **키워드별 5-10건씩 시트 분리**
- 자격 미해당 공고는 별도 시트에 사유와 함께 표시
- **공고 공유는 공고번호 기반** (나라장터 SPA 특성상 공고별 직접 URL이 없으므로)

---

## 핀인사이트 나라장터 등록업종 (자격 필터 기준)

핀인사이트는 나라장터에 다음 5개 업종으로 등록되어 있다. 이 5개 코드 외의 자격을 요구하는
공고는 입찰 참여 불가능하다.

| 코드 | 업종명 | 매칭되는 사업 유형 |
|------|-------|------------------|
| **1468** | 소프트웨어사업자 (컴퓨터관련서비스사업) | 시스템 구축·SI·SW 개발·플랫폼 구축·운영 |
| **1469** | 소프트웨어사업자 (디지털콘텐츠개발서비스사업) | AI·챗봇·디지털 콘텐츠 개발·교육 콘텐츠 |
| **1470** | 소프트웨어사업자 (DB 제작 및 검색서비스사업) | DB 구축·자료처리·데이터 분석·검색시스템 |
| **1169** | 학술연구용역 | 정책연구·R&D·타당성 검토·로드맵·교육평가 |
| **9999** | 기타자유업종 | 일반 용역 (특정 업종 면허 제한 없는 경우) |

**자격 판단 원칙:**
- 공고가 요구하는 업종 코드 ∈ {1468, 1469, 1470, 1169, 9999} → 자격 통과
- 공고가 면허 제한 없음(또는 9999 허용) → 자격 통과
- 그 외 (예: 1170 시설관리, 1465 정보통신공사 등) → 자격 미해당

**참고**: 공고문에 면허 제한이 명시되지 않은 경우(특히 협상에의한계약), 사업 내용을 보고
위 5개 업종 중 어느 것으로 수행 가능한지 추정하여 매칭한다. 매칭 0개면 자격 미해당.

## 실행 절차

### Step 1: 공고 수집

#### 1-A. OpenAPI 우선

조달청 [나라장터 입찰공고정보서비스](https://www.data.go.kr/data/15129394/openapi.do) 사용.
환경변수 `G2B_API_KEY` 또는 사용자 입력.

```python
import requests, os
BASE_URL = "http://apis.data.go.kr/1230000/BidPublicInfoService/getBidPblancListInfoServc"

def fetch_bids(keyword, start_date, end_date, num_rows=100):
    params = {
        "ServiceKey": os.environ.get("G2B_API_KEY"),
        "pageNo": 1, "numOfRows": num_rows,
        "inqryDiv": 1,
        "inqryBgnDt": start_date.strftime("%Y%m%d") + "0000",
        "inqryEndDt": end_date.strftime("%Y%m%d") + "2359",
        "bidNtceNm": keyword, "type": "json"
    }
    response = requests.get(BASE_URL, params=params, timeout=30)
    if response.status_code != 200: return None
    return response.json().get("response", {}).get("body", {}).get("items", [])
```

**OpenAPI 활용 팁**: 공고 상세 조회 API(`getBidPblancListInfoServcDetail`)로 면허제한정보·
참가자격 조건을 추가 수집 가능. 이 정보가 있으면 핀인사이트 등록업종 5개와 직접 코드 매칭 가능.

#### 1-B. Claude in Chrome 폴백

API 실패·키 없음·네트워크 차단 시:

1. `navigate`로 `https://www.g2b.go.kr/` 접속
2. 공지사항 팝업이 뜨면 "오늘 하루 안 보기" 체크 후 닫기
3. 전체메뉴 → 입찰 > 입찰공고 > 입찰공고목록 클릭
4. 검색 폼에서 공고명에 키워드 입력, "최근 3개월" 선택 후 검색
5. JavaScript로 결과 테이블 데이터 추출 (`R26[A-Z]{2}\d{8}` 패턴 매칭)
6. 키워드별 반복, `window.__bidResults` 배열에 누적 저장

### Step 3: 핀인사이트 등록업종 자격 매칭

#### 3-1. 명시적 자격 코드 매칭 (1순위)

공고 상세에 참가자격 코드가 명시된 경우, 핀인사이트 5개 코드와 직접 비교.

```python
PININSIGHT_CODES = {'1468', '1469', '1470', '1169', '9999'}

def check_explicit_qualification(required_codes):
    """공고가 요구하는 자격 코드와 핀인사이트 등록 코드 매칭"""
    if not required_codes:
        # 자격 제한 없으면 9999(기타자유)로 통과
        return ['9999 (자격제한 없음)']
    
    matched = []
    for code in required_codes:
        if code in PININSIGHT_CODES:
            matched.append(code)
    return matched
```

#### 3-3. 자격 미해당 추가 판단

```python
def is_disqualified(title, biz_type, matched_codes, required_codes=None):
    """핀인사이트 자격으로 커버 불가능한 공고 판단"""
    reasons = []
    
    if biz_type == '공사':
        reasons.append('업무구분 공사 (시공자격 없음)')
    
    # 명시적 자격 요구가 있고, 핀인사이트 코드 매칭 0개
    if required_codes and not matched_codes:
        reasons.append(f'면허제한 불일치 (요구: {",".join(required_codes)})')
    
    # 자격 요구 없거나 명시 없는 경우, 추정 매칭도 0개면 미해당
    if not required_codes and not matched_codes:
        reasons.append('등록업종 매칭 없음')
    
    # 단순 라이선스 유통 (개발/공급 아닌 단순 중개)
    if any(k in title for k in ['라이센스 구매', '라이선스 구매', '라이센스 임대',
                                   '라이선스 임대', '라이선스 연간 사용권']):
        if '구축' not in title and '개발' not in title:
            reasons.append('단순 라이선스 유통')
    
    # 단순 행사·기획 (강점 영역 아님)
    if any(k in title for k in ['환경교육주간 행사', '국제교류', '주간 행사',
                                   '체험 사업 위탁', '예비 산림']):
        reasons.append('단순 행사·기획 (강점 영역 아님)')
    
    # 물품 구매·유통 (제조·유통 종목 미보유)
    if biz_type == '물품':
        if any(k in title for k in ['라이센스 구매', '라이선스 구매', 'ODTK',
                                       '서버 구매', '소프트웨어 라이선스']):
            reasons.append('물품 구매·유통')
    
    return reasons
```

### Step 4: 적합도 점수화 (자격 통과 공고만)

**115점 만점**:

#### 4-1. 도메인 적합도 (50점)
- 빅데이터+AI 동시 매칭: 50
- 빅데이터·데이터분석 직접: 45
- AI 응용 사업 직접: 45
- 일부 키워드 매칭: 30
- 교육 일반: 20

#### 4-2. 교육 특화 가산 (최대 +15)
- AI·데이터 리터러시 교육 키워드: +5
- 대상자가 재직자·청년·취준생·대학생·HRD: +10
- 둘 다 충족: +15

- 나라장터 OpenAPI 키는 사용자가 직접 발급. 사내 환경 추천 (네트워크 차단 회피)

- **명시적 면허 제한이 있는 공고는 코드 직접 비교가 가장 정확** — Step 3-1 우선
- 추정가격 비공개 시 "예산 미공개" 표시
- 매주 자동 실행 약속 안 함 — 매번 명시적 호출
- 적합도 점수는 참고용. 최종 판단은 사용자
- 자격 미해당 공고도 별도 시트로 표시
- **공고별 직접 링크는 첨부하지 않음 (나라장터 SPA 특성)** — 공고번호·공고명 복사 방식 사용
- **핀인사이트 등록업종이 변경되면 PININSIGHT_CODES 상수 업데이트 필요**

## 엣지 케이스 처리

| 상황 | 처리 방법 |
|------|----------|
| API 키 없음 | Chrome 폴백 자동 전환 |
| 네트워크 차단 | Chrome 폴백 또는 사내 서버 실행 안내 |
| 수집 결과 0건 | 확장 키워드 1회 시도, 그래도 없으면 사용자 확인 |
| 수집 500건 초과 | 자동 필터 강화 + 추가 옵션 제시 |
| 동일 공고 중복 | 입찰공고번호로 중복 제거 |
| 추정가격 비공개 | 가격 필터 건너뛰고 표시 |
| 유찰 후 재공고 | "재공고" 표시 (관심도 증거) |
| 마감 D-7 미만 | ⚠️ 표시하되 제외하지 않음 |
| CAPTCHA 발생 | 사용자 수동 처리 요청 |
| 광범위 키워드 (예: "교육") | 확장 키워드 자동 추가 (양성/리터러시/부트캠프) |
| 페이지당 10건 제한 | 100건으로 변경 후 재수집 또는 키워드 세분화 |
| 자격 미해당 다수 | 별도 시트 표시, 검토 가능하게 함 |
| 공고에 면허제한 정보 없음 | 사업 내용 기반 추정 매칭(Step 3-2) 적용 |
| 1170/1465 등 다른 SW업종 요구 | 자격 미해당 (예: 1465 정보통신공사) |
